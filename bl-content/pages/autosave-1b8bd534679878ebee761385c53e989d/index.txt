<p>A lightweight, customizable accessibility toolkit that provides users with visual and reading assistance tools to improve their browsing experience.</p>
<h2>Overview</h2>
<p>This accessibility widget offers a comprehensive set of tools designed to help users with various accessibility needs, including visual impairments, dyslexia, ADHD, motor difficulties, and more. The widget is fully keyboard-accessible, privacy-focused, and has minimal performance impact.</p>
<h2>Features</h2>
<h3>Display Modes (4 options)</h3>
<ul>
<li><strong>Light Mode</strong> - Traditional bright background with dark text</li>
<li><strong>Dark Mode</strong> - Dark background with light text, reduces eye strain</li>
<li><strong>High Contrast Mode</strong> - Maximum text-to-background contrast</li>
<li><strong>Greyscale Mode</strong> - Removes all colors from the page</li>
</ul>
<p>On first visit, the widget follows the user's device preferences: dark mode if <code>prefers-color-scheme: dark</code> is set, otherwise high contrast if <code>prefers-contrast: more</code> is set.</p>
<h3>Text Controls (3 options)</h3>
<ul>
<li><strong>Normal Text Size</strong> - Standard size as designed</li>
<li><strong>Large Text Size</strong> - Increases all text by 20%</li>
<li><strong>Bold Text</strong> - Increases all text by 20% (like Large Text Size) and makes all of it bold</li>
</ul>
<h3>Visual Aids (4 toggles)</h3>
<ul>
<li><strong>Large Cursor</strong> - Increases cursor size approximately 3x</li>
<li><strong>Highlight Links</strong> - Adds yellow background and underline to all links</li>
<li><strong>Hide Images</strong> - Hides images and displays their alt text in their place (decorative images with an empty <code>alt</code> are simply hidden)</li>
<li><strong>Reading Mask</strong> - Creates a spotlight effect that highlights the current reading line, which can help users with dyslexia keep their place and read more comfortably. The clear band follows the mouse, touch, or keyboard focus</li>
</ul>
<h3>Additional Features</h3>
<ul>
<li><strong>Reset All Settings - Returns all settings to defaults</strong></li>
<li><strong>Automatic Settings Persistence - User preferences are saved to localStorage</strong></li>
<li><strong>Full Keyboard Accessibility - All features are keyboard-navigable</strong></li>
<li><strong>Screen Reader Support - The toggle button's accessible description lists the settings currently active, matching the visual marker on the button</strong></li>
<li><strong>Privacy-Focused - All data stored locally, nothing sent to servers</strong></li>
</ul>
<h2>Performance</h2>
<ul>
<li>Lightweight, with minimal impact on page load times: no dependencies and no network requests after the page loads</li>
<li>Compressed file size: approximately 10KB (CSS and JavaScript, gzipped)</li>
<li>Reading mask updates at 60 FPS for smooth movement</li>
<li>Uses approximately 200 bytes of localStorage</li>
</ul>
<h2>Browser Support</h2>
<p>Works on all modern browsers:</p>
<ul>
<li>Chrome 80+</li>
<li>Firefox 74+</li>
<li>Safari 14+</li>
<li>Edge 80+</li>
<li>Opera 67+</li>
</ul>
<p>Mobile support:</p>
<ul>
<li>iOS 14+</li>
<li>Android (Chrome 80+)</li>
</ul>
<p>In practice, any browser version released since late 2020.</p>
<h2>Who Benefits?</h2>
<p>The widget helps users with:</p>
<ul>
<li><strong>Visual Impairments</strong> - Large cursor, high contrast, large text, bold text, highlight links</li>
<li><strong>Dyslexia</strong> - Reading mask (often the most helpful), bold text, large text, high contrast</li>
<li><strong>ADHD</strong> - Reading mask, hide images, greyscale mode, dark mode</li>
<li><strong>Light Sensitivity/Photophobia</strong> - Dark mode, greyscale mode, reading mask</li>
<li><strong>Motor Impairments</strong> - Large cursor, highlight links, large text (all fully keyboard-accessible)</li>
<li><strong>Cognitive Disabilities</strong> - Reading mask, hide images, highlight links, high contrast</li>
<li><strong>Color Blindness</strong> - High contrast, greyscale, highlight links</li>
<li><strong>Age-Related Vision Changes</strong> - Large text, large cursor, high contrast, bold text</li>
<li><strong>Fatigue and Eye Strain</strong> - Dark mode, reading mask, large text, high contrast</li>
</ul>
