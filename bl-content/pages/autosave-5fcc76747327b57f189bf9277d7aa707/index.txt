<div class="page-intro">
<p class="text-large">A self-contained web application for conducting WCAG 2.2 Level AA accessibility audits. Built as a single HTML file with no dependencies.</p>
</div>
<h2>What it does</h2>
<p>The tool presents a structured checklist of accessibility tests aligned with WCAG 2.2 Level AA. For each test you can:</p>
<ul>
<li>Mark the result as <strong>Pass</strong>, <strong>Fail</strong>, or <strong>N/A</strong></li>
<li>Add a comment or description of any issue found</li>
<li>Track overall progress across all 15 sections and ~90 checks</li>
</ul>
<p>Progress is saved automatically in the browser using <code>localStorage</code>. When you are ready, clicking <strong>Generate report</strong> downloads a self-contained HTML file summarising the results, including a dedicated section for all failures and your comments.</p>
<h2>Requirements</h2>
<ul>
<li>Any modern web browser (Chrome, Firefox, Edge, Safari)</li>
<li>A web server or local server such as WAMP (for local use) or any standard hosting for live use</li>
<li>No internet connection required once the file is loaded</li>
<li>No installation of Node.js, PHP, databases, or any other software</li>
</ul>
<h2>How to use</h2>
<ol>
<li><strong>Fill in the site details</strong> — enter the site name, URL, tester name, date, and optional scope notes. These appear in the generated report.</li>
<li><strong>Click Start testing</strong> — the checklist loads with 15 sections accessible via the tab bar at the top.</li>
<li>Work through each section — for every check, click Pass, Fail, or N/A. Clicking the same button again deselects it if you change your mind.</li>
<li><strong>Add comments</strong> — a comment box appears automatically when you mark something as Fail. You can type a description of the issue, the affected page, or any other relevant note.</li>
<li><strong>Monitor progress</strong> — the progress bar and counters at the top update as you go. Sections with failures are highlighted in red in the tab bar.</li>
<li><strong>Generate the report</strong> — click Generate report at the bottom right. A HTML file downloads automatically. Open it in any browser to view or print it.</li>
<li><strong>Return to the audit list</strong> — click All audits in the header or footer at any time. Your current progress is saved automatically. From the list you can resume any previous audit, start a new one, export a backup, or delete audits you no longer need.</li>
</ol>
<blockquote>
<p><strong>Note:</strong> All audits are saved in your browser automatically. If you close the tab and reopen the tool in the same browser on the same machine, your audits will be there. Audits are not shared between different browsers or different machines. To keep a permanent backup, use <strong>Export all</strong> on the audit list page to download a <code>.json</code> file you can import later.</p>
</blockquote>
<h2>Managing multiple audits</h2>
<p>The tool supports multiple saved audits at once. Each audit is stored independently under a unique ID, so you can run and return to as many audits as you like without any configuration changes.</p>
<h3>Starting a new audit</h3>
<p>Fill in the site details form and click Start testing. The new audit is saved automatically and will appear in the list next time you visit the audit list page.</p>
<h3>Switching between audits</h3>
<p>Click All audits in the header or footer at any time. Your current progress is saved automatically, and you are taken back to the list where you can resume any previous audit.</p>
<h3>Backing up your audits (export)</h3>
<p>On the audit list page, click Export all to download a .json file containing all your saved audits. Store this somewhere safe — it can be used to restore your audits if you ever clear your browser data.</p>
<h3>Restoring from a backup (import)</h3>
<p>Click Import backup on the audit list page and select a previously exported .json file. Imported audits are merged with any audits already saved in the browser, so nothing is overwritten.</p>
<h3>Deleting an audit</h3>
<p>Each saved audit has a Delete button on the audit list page. You will be asked to confirm before anything is removed.</p>
